# Work Packages

Choose one procedure:

- Create or revise a package: read [standard.md](references/standard.md) and use
  the templates under `assets/` when helpful.
- Execute an existing package: read [execution.md](references/execution.md), the
  package `README.md`, and only the active package files needed for the next
  runnable item.

Keep planning artifacts separate from shipping code unless the user or
repository requires the package itself to be versioned.
